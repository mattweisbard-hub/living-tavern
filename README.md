# Living Tavern 2.1

Install Python, Git and Ollama; pull qwen2.5:1.5b once. Clone the repository and double-click Play.bat. It checks GitHub, installs changed dependencies in .venv, starts Ollama if necessary and opens the browser. Play_Offline.bat skips the initial Git check. In-game Update & Restart works when launched by Play.bat at http://127.0.0.1:8000. Keep the launcher window open. Stop with Ctrl+C. Model preferences in model.txt and SQLite saves are ignored by Git. Existing local-v2 saves are reused. Updates never reset tracked edits. Dialogue uses a medieval world prompt; earlier NPC replies are excluded from the new prompt to avoid reinforcing modern knowledge. This is a prototype, not a guaranteed lore filter.
